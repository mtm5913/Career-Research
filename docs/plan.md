## Two layout alternatives using the same content

Both alternatives use the same introduction, individual RAG and group-system case studies, evidence links, and professional links. They change the order and emphasis, not the underlying claims.

| | A — Research-first | B — Demo-first |
|---|---|---|
| Page order | Introduction → featured project cards → research-led case studies → professional links | Introduction → prominent demo → product-led case studies → professional links |
| Case-study order | Problem → question → methods → evidence → decision → results/limits | Result → interface → process → evidence/limits |
| Reader benefit | Makes the reasoning and my research contribution easy to inspect | Gives quick access to the product and visible output |

**Selected: A — Research-first.** UX research is my preferred direction, and the target reader needs to assess how I move from observations to decisions. A prominent app/code link near the top of each relevant case study can still provide quick access. These are written layout alternatives, not built or peer-tested wireframes.
